Before you buy

How demos work

Demos are full-featured, with a limitation. Buy a plugin to unlock it with a license key.

  1. Download

    Grab the demo for the plugin you want. It installs the same way the full plugin does.

  2. Play it

    The demo is the real plugin, with a limitation so you can hear it in a session before you pay.

  3. Unlock

    Buy opens a checkout on this page. Your license key takes the limitation off.

How do I install in Ableton?

Edit this answer Download the Mac installer and run it. In Ableton, open Settings, then Plug-Ins, and turn on Audio Units and VST3. If a plugin is missing, click Rescan. Punch loads as an effect.

How do license keys work?

Edit this answer After you buy, Lemon Squeezy emails you a license key. Open the plugin, paste the key, and the demo limitation turns off. Keep that email somewhere safe.

Does this work on Mac and Windows?

Edit this answer The plugins run on Mac today: Apple silicon and Intel, macOS 11 or newer. Windows versions are coming. Each card lists its formats.
