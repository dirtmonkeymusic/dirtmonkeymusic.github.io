Installing Dirt Monkey plugins on Windows

Every Dirt Monkey plugin comes as one Setup.exe (for example Punch-Win-1.0.7-Setup.exe). The steps are the same for all of them. You need 64-bit Windows 10 or 11.

Pictures marked PLACEHOLDER are stand-ins until real screenshots are taken on Windows.

  1. Close Ableton, then double-click the ...-Setup.exe you downloaded.

    If Windows says "Windows protected your PC" (this happens while a build is unsigned): click More info, then Run anyway. Click Yes when Windows asks for permission.

  2. Click Next.
  3. If the plugin has a Standalone app, you can leave it ticked or untick it. The VST3 plug-in is always installed. Click Install. (Plugins with no standalone skip this page.)
  4. Wait a few seconds while it installs.
  5. Click Finish. The plug-in is now in C:\Program Files\Common Files\VST3.
  6. Open Ableton > Settings > Plug-Ins > Rescan. Make sure Use VST3 Plug-In System Folder is on. The plugin is listed under Plug-Ins > VST3 > Dirt Monkey.

Where things go

  • VST3 plug-in: C:\Program Files\Common Files\VST3\<Name>.vst3
  • Standalone app (if you ticked it): C:\Program Files\Dirt Monkey\<Name>.exe, with a Start menu shortcut under Dirt Monkey

Updating

Run the new Setup.exe. It replaces the old version. Your sets and presets are not touched.

Uninstall

Windows Settings > Apps > Installed apps, find Dirt Monkey <Name>, click Uninstall.

Problems

  • Plugin not listed in Ableton: click Rescan again, then restart Ableton.
  • "Windows protected your PC": click More info, then Run anyway.
  • Silent install (IT or testing): <Name>-Win-<version>-Setup.exe /S from an administrator prompt. Silent uninstall: "C:\Program Files\Dirt Monkey\Uninstall <Name>.exe" /S
